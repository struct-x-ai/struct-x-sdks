# Security policy

Please report vulnerabilities privately through GitHub: open the **Security** tab of this repository and choose **Report a vulnerability**. Don't open a public issue for a security problem.

Include the package and version, what you found, and how to reproduce it. We aim to acknowledge reports within 3 business days.

This policy covers the code in this repository (the SDKs and the MCP server). Issues with the Struct-X API service itself can be reported the same way.
